# React Query Lab

React Query 주요 기능을 실험하고 동작 방식을 시각화하는 프로젝트 입니다.

## 실험 목적

React Query를 단순히 사용하는 것이 아니라 기존 useEffec 기반 데이터 패칭 방식과 비교하여 서버 상태 관리의 필요성을 이해하는 것이 목적입니다.

## 실험

| Feature   | Description               |
| --------- | ------------------------- |
| Cache     | Query Cache 동작 확인     |
| staleTime | Fresh / Stale 상태 비교   |
| Mutation  | 데이터 변경 및 Query 갱신 |

## Tech Stack

- React
- React Query
- React Router
- Tailwind CSS
- Vite
